# Addis Eats

A simple static Ethiopian food menu built with React and Vite.

## Features

* React functional components
* Reusable `Dish` component
* `Header` component
* Menu data stored in an array
* Menu rendered using `.map()`
* React `key` props for list items
* JSX

## How to Run

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL shown in the terminal.

## Project Structure

* `src/App.jsx` - Main application component and menu data
* `src/Dish.jsx` - Reusable dish component
* `src/main.jsx` - React entry point
* `src/index.css` - Styling
